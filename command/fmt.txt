Usage: grammar fmt ARGUMENT

Formats input files inplace. Any syntax error is printed to
the console and the input file is left unchanged.

Argument:
PATH                PATH is a file, Format code inplace,
    --stdout PATH   Print formatted output to stdout. Do not modify input file.
    --stdin         Format code from stdin, output to stdout.
-s  --separator N   The number of blank lines (N) that terminates a group; a change in the kind of the declaration (binding, rule, proc) ends a group too (see implementation/08-fmt.md). Defaults to 1. This flag is ignored if less than 1.
-h, --help          Print this message.
